# CODEX PANEL - বাংলাদেশের সেরা ডিজিটাল সার্ভিস

একটি আধুনিক এবং প্রাণবন্ত ডিজিটাল সার্ভিস প্যানেল ওয়েবসাইট।

## ফিচারস ✨

- 🎨 আধুনিক এবং আকর্ষণীয় ডিজাইন
- 🌈 রংধনু গ্রেডিয়েন্ট থিম সিস্টেম
- 📱 সম্পূর্ণ রেসপন্সিভ ডিজাইন
- ⚡ দ্রুত লোডিং অ্যানিমেশন
- 🌙 থিম চেঞ্জার (Black → White → Purple)
- 💬 টেলিগ্রাম ইন্টিগ্রেশন

## দ্রুত শুরু করুন 🚀

### Vercel-এ ডিপ্লয় করতে:

1. আপনার GitHub রিপোজিটরিতে এই ফাইলগুলি পুশ করুন:
   ```
   vercel.json
   package.json
   public/index.html
   ```

2. Vercel ড্যাশবোর্ডে যান: https://vercel.com

3. "Add New" → "Project" ক্লিক করুন

4. আপনার GitHub রিপোজিটরি সিলেক্ট করুন

5. "Deploy" বাটনে ক্লিক করুন

6. কয়েক মুহূর্তের মধ্যে আপনার সাইট লাইভ হবে! 🎉

### লোকালি টেস্ট করতে:

```bash
# Python 3 ব্যবহার করুন
python -m http.server 8000

# অথবা Node.js ব্যবহার করুন
npx serve public
```

তারপর ব্রাউজারে খুলুন: `http://localhost:8000`
